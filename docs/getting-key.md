# 如何获得微信数据库密钥

## 密钥是什么

微信电脑版的聊天数据库是加密的。解密需要一串 **32 字节密钥**，通常写成
**64 个十六进制字符**，例如：

```text
0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef
```

它不是你的微信登录密码，也不是手机号或验证码。它只用于解密**你自己账号**的
`db_storage`。

## 情况一：你已经有一个 key.txt

很多导出工具会把密钥保存成 `key.txt`。直接在本工具里选择这个文件即可，
不需要手动输入。

## 情况二：你手里有 64 位密钥

在 GUI 的「或直接粘贴 64 位密钥」输入框里粘贴，或者在 CLI 里使用
`--key-file` 指向一个只包含这串字符的文件。

## 情况三：你什么都没有

本工具**不提供**自动提取密钥的功能，原因是：

- 从微信进程内存读取密钥属于绕过客户端保护，可能违反微信服务条款；
- 这类代码容易触发安全软件，也让项目面临平台下架风险；
- 不同微信版本的密钥机制不同，自动提取难以长期维护。

可行做法是：使用你信任的、仍在维护且能获取源码的社区密钥导出工具，在**你自己
拥有并授权的电脑**上导出 `key.txt`，然后交给本工具。请注意：

- 不要使用网盘转包、破解版或来历不明的 exe；
- 只在你自己的设备、自己的账号上使用；
- 导出后妥善保管密钥，不要上传或分享；
- 部分地区的法律可能限制绕过技术措施，请自行确认合规性。

本仓库不捆绑、不背书任何第三方密钥提取工具。

## 验证密钥是否正确

```bash
wce doctor --db-dir "你的/db_storage" --key-file key.txt
```

如果输出「解密成功」且能看到分片和会话数量，说明密钥正确。密钥错误时会在
数据库头部校验阶段明确失败，不会静默导出垃圾数据。

## 安全建议

- 密钥等同于数据库的钥匙，泄露后别人可以解密你的聊天记录。
- 不要把密钥写进截图、issue、聊天记录或公开仓库。
- 使用完毕后删除临时密钥文件，或放进系统凭据管理器/加密盘。
