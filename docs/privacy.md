# 隐私与数据安全

## 本地处理

- 工具不发起任何网络请求，没有遥测、统计或自动更新。
- 密钥只在内存中使用；不会写入日志、manifest 或命令行参数。
- 临时解密数据库默认放在系统临时目录，程序正常/异常退出时删除。

## 临时目录

导出时需要把加密数据库解密到临时目录，才能用 SQLite 查询。

- 默认在退出时 `rmtree`。
- `--keep-work` 会保留，并打印路径；此时目录里是**明文聊天数据库**。
- 如果进程被强杀或断电，临时目录可能残留。建议开启全盘加密，并定期清理 `wce-*` 目录。

## 输出文件

导出的 CSV / Excel / HTML / PDF / Word 都是明文，包含完整聊天内容。

- 不要把导出目录放进同步盘或公开仓库。
- 分享前请先脱敏。
- 本项目的 `.gitignore` 会阻止 `*.db`、`*.db-wal`、`key*`、`out/` 等被提交，但不要依赖它兜底。

## 日志

- 默认只记录会话数、条数、格式和错误码。
- 64 位十六进制密钥会被自动替换为 `<redacted-key>`。
- 不记录消息正文。

## 合规

- 仅导出你本人的数据，或已取得所有参与者明确授权的数据。
- 导出他人聊天记录可能涉及个人信息保护法、GDPR、通信秘密等法律。
- 请遵守微信服务条款和当地法律。
